# Before the visual flip

The constructivist interface as it stood immediately before the change of
direction, rendered through the generated stylesheet rather than the
hand-written one — so these images also demonstrate that the token layer
reproduced the previous appearance.

They are the visual evidence for
`design-system/screen-translator/decisions/0002-liquid-glass-direction.md`,
and the "before" half of the before/after that ADR promises.

Regenerate the equivalents after the flip with:

    .venv\Scripts\python.exe scripts\render_ui_preview.py
    .venv\Scripts\python.exe scripts\render_overlay_preview.py
